# پروژه MusicBox برای Android Studio

این پروژه یک پخش‌کننده و مدیریت‌کننده ساده موسیقی‌های محلی گوشی است.

## امکانات
- خواندن فایل‌های صوتی موجود در حافظه گوشی
- نمایش نام آهنگ، خواننده و مدت زمان
- جستجو بر اساس نام آهنگ یا خواننده
- افزودن و حذف آهنگ از علاقه‌مندی‌ها
- پخش، توقف/ادامه، آهنگ قبلی و بعدی
- رابط کاربری تیره و فارسی

## روش ساخت APK
1. فایل ZIP را از حالت فشرده خارج کنید.
2. Android Studio را باز کنید و گزینه **Open** را بزنید.
3. پوشه `MusicBoxAndroid` را انتخاب کنید.
4. صبر کنید Gradle Sync کامل شود. در صورت درخواست، نسخه Gradle و Android SDK پیشنهادی Android Studio را نصب کنید.
5. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** استفاده کنید.
6. پس از پایان ساخت، روی **locate** بزنید تا فایل APK را پیدا کنید.
7. APK را به گوشی منتقل و نصب کنید. ممکن است لازم باشد اجازه نصب برنامه از همان منبع را در تنظیمات گوشی فعال کنید.

## نکته
این محیط امکان اجرای Android SDK و ساخت مستقیم APK را ندارد؛ بنابراین فایل تحویلی، پروژه کامل قابل باز شدن در Android Studio است، نه APK کامپایل‌شده. برای ساخت APK باید مراحل بالا را در Android Studio انجام دهید.

## نکته درباره موسیقی
برنامه فقط فایل‌های صوتی موجود روی گوشی را فهرست می‌کند و موسیقی یا اشتراک آنلاین ارائه نمی‌دهد.
